# 无感录音(手表)

> Issue #5。目标:谈话场景里,除了「看一眼时间」,不需要任何显眼动作。
> **2026-11-11 更新:VAD 自动开录经甲方真机体验撤下(环境音误触太容易),改为手动触发;后台续录保留。**

## 使用流程

1. 谈话前抬腕看一眼 DayTap——就是块普通表盘(大字时钟),无录音痕迹
2. **开始**:点一下屏幕,或**握拳**(见下方绑定);触觉确认,不出声不亮屏
3. 录着按表冠回表盘、腕朝下都**继续录**(audio 后台模式)
4. **停止**:同上(点按/握拳);自动保存并传 iPhone
5. 录错了:**「丢弃当前录音」快捷指令**静默丢弃(或长按删除由手机端管理)
6. 手机 DayTap 列表:试听、长按重命名、分享(文件名跟随)

状态一眼可读:灰点=闲,红点+计时=录音中。闲置界面有「再传一次」补传未确认文件。

## 绑定握拳(AssistiveTouch,Series 4+)

手表 **设置 → 辅助功能 → AssistiveTouch → 手势 → 握拳 → 运行快捷指令 → 「DayTap 无感录音启停」**(快捷指令在 Shortcuts 里选 DayTap 的动作)。绑定后不看屏幕即可启停,手放桌上或腿上握拳,视觉不可见。

双捏两次(watchOS 10 双击,S9/Ultra 2+)触发屏幕主操作(全屏点按),免费备用。表盘角标小组件(#12)点一下打开 DayTap。

## 演进记录(VAD 撤下,备查)

首版做过「进入即武装 + VAD 人声自动开录 + 3-5 分钟滚动缓冲」:武装态录进 tmp(`AudioCapture.startBuffer`),人声阈值触发时 POSIX rename 晋级(`AudioCapture.promote`),同一文件自带触发前缓冲。模拟器全链路验证通过(见 #13),但真机环境音误触率高,甲方定夺改手动。VAD 参数留档:voiceLevel 0.32 / voiceHold 0.8s / voiceDrop 0.22 / armedTimeout 600s(`StealthTuning`,已随撤下移除,git 历史可考)。缓冲与晋级实现保留在 AudioCapture,备 v2 调参回归。

## 合规注

作为对话一方录音,在中国劳动争议中一般可作证据(以不严重侵害他人合法权益、不违反法律禁止性规定为限);其他法域规则不同。App 不做法律承诺,不做反检测类对抗功能。
