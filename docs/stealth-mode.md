# 无感录音(手表)

> Issue #5。目标:谈话场景里,除了「看一眼时间」,不需要任何显眼动作。

## 使用流程

1. 走进谈话前,抬腕看一眼 DayTap——**进入即武装**(白点 + 大字时钟,看着就是块表盘)
2. 有人开口说话 → 自动开录(红点),**从武装时刻起的声音都在**,开场白不丢
3. 全程腕朝下/回表盘照常录(audio 后台模式)
4. 停止:点一下屏幕,或**握拳**(见下方绑定);停完自动重新武装,可连续多段
5. 录完自动传 iPhone,手机列表里照常试听/分享

状态一眼可读:灰点=闲置,白点=武装待命,红点=录音中。武装 10 分钟没人声自动静默解除(省电)。点按 = 闲置→武装、武装→立刻开录、录音中→停止保存。「解除无感模式」意图可静默退出且不保存。

## 绑定握拳(AssistiveTouch,Series 4+)

手表 **设置 → 辅助功能 → AssistiveTouch → 手势 → 握拳 → 运行快捷指令 → 「无感录音启停」**(快捷指令在 Shortcuts 里选 DayTap 的动作)。绑定后不看屏幕即可启停,手放桌上或腿上握拳,视觉不可见。

双捏两次(watchOS 10 双击,S9/Ultra 2+)会触发屏幕主操作,即全屏点按,免费备用。

## 判定参数(代码 `StealthTuning`)

| 参数 | 值 | 含义 |
|---|---|---|
| voiceLevel | 0.32 | 音量高于此开始计人声 |
| voiceHold | 0.8s | 持续超过此时长才开录(防一声咳嗽) |
| voiceDrop | 0.22 | 低于此才重置计时(迟滞,防阈值边缘抖动) |
| armedTimeout | 600s | 武装静默超时自动解除 |

## 合规注

作为对话一方录音,在中国劳动争议中一般可作证据(以不严重侵害他人合法权益、不违反法律禁止性规定为限);其他法域规则不同。App 不做法律承诺,不做反检测类对抗功能。
