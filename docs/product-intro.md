# DayTap 功能介绍

> 腕上按一下,回到手机时,它已经是文字、摘要和待办。

**DayTap = 按需录音 → 全文与摘要 → 可勾选的待办。** 录音这件事像语音备忘录一样简单;录完之后,比语音备忘录多走三步:转写、整理、待办落地。

更新于 2026-11-14(当晚五 tab 版),对应真机在用版本(iPhone 17 + Apple Watch Series 11)。

---

## 一条动线

### 1. 录:一秒进入

- **手表红色大按钮**:点一下开始,再点停止。屏幕上只有这一颗按钮
- **敲桌两下**就能启停——手表闲时在听,不用抬手点屏幕
- **握拳**启停(需在手表设置里把 AssistiveTouch 手势绑定到快捷指令)
- **表盘小组件**:不打开 App,点磁贴直接录
- **手机也能直接录**:底栏红钮;录着退后台、锁屏不停,和语音备忘录一致

### 2. 传:放下手腕就发生

- 录完自动排队传回 iPhone,不需要任何操作
- **确认即删**:手机确认收到后,手表上的原件随即删掉,不占手表存储;未确认的绝不删
- 传坏了不会装作没事:截断的文件手机拒收、自动重传,坏数据不进库

### 3. 转:回来已是全文

- 音频一到手机**自动转文字**,带时间戳分段
- 优先本机转写(iOS 26);国行设备无 Apple 智能时,可配云端大模型兜底
- 转写失败在列表里看得见,左滑就能重试

### 4. 整理:摘要卡,不是一堆音频

- 每条录音自动生成**标题、类别、摘要、待办**
- 类别(会议/活动/灵感/日常/其他)可手动纠偏
- **待办可以勾掉**:列表里轻点即完成;还能一键送进系统**提醒事项**或**日历**
- 「周五前给他回复」这类说法,AI 会识别成截止时间,一并带进日历

### 5. 用:找得到、听得快、带得走

- **搜索**标题和全文;命中行高亮,点一下跳到那一刻
- 全文页**点句跳播**:播到哪句哪句高亮、自动滚动跟读
- **密度进度条**:哪段在说话、哪段是静音,进度条颜色深浅一眼看出,已播部分换红
- 倍速 1x / 1.5x / 2x、一键**跳过静音**
- **本周回顾**:条数、时长、类别分布、全部待办,一屏看完
- **导出** Markdown / 纯文本 / JSON,可选完整内容或只要摘要卡
- 按天分组、按类别筛选;误删进**最近删除**,30 天内可恢复

## 主界面:五个入口

打开 App,底栏五个 tab,各管一段:

- **计划** — 今天该做什么:跨录音聚合的今日待办(逾期在前)、今日时间线(录音+待办+日历混排)、AI 给的今日安排建议
- **今天** — 每天的回顾:今日录音概览;健康、人物、情绪的每日一段正在落位
- **记录** — 全部录音:按天分组、搜索、试听、转写全文、摘要卡、导出
- **成长** — 本周回顾:条数/时长/类别分布
- **我的** — 设置:AI 模型、iCloud、数据去向

## 隐私与数据去向

设置页里有一屏明文清单,这里是同样的内容:

- **本机**:音频、转写、摘要都存在这台手机上;手表原件在手机确认收到后即删
- **AI(可选)**:出设备的只有转写文字,和你选填的「关于我」背景段;**音频永不外发**。不配 AI 也能用,只是没有摘要和待办
- **iCloud 备份**:引擎已就绪,当前泊车——免费开发者账号开不了该能力,启用前不会有任何 iCloud 流量;将来可整体关闭,或只备份文字

## 它不是什么(诚实版)

- **不是全天候录音硬件**:手表录音是前台行为,不承诺后台无中断
- 不集成得到;想把音频送进得到工作流,到手机后走系统分享面板
- 还没有 TestFlight / App Store,只能 Mac + Xcode 侧载
- 国行 iPhone 暂无 Apple 智能(官方口径:随 iOS 27.3 推送),深度整理依赖可选的云端模型

## 给谁用

- 想把手表当「最短路径想法捕获」的人:开会、散步、通勤,按一下就录
- 录完就再没打开过语音备忘录的人——DayTap 替你把收尾做完
- 不适合:需要 Auday 式全天无中断录音的人(那是另一类产品)
